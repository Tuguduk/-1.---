## Постановка
Загрузка 4 производственных линий в 3 смены для выпуска 4 продуктов. Переменные непрерывные: объём каждого продукта на каждой линии в каждой смене. Цель — максимизировать суммарный выпуск.

## Структура
- `data/instance.json` — полный набор параметров и описание генерации;
- `data/*.csv` — исходные таблицы параметров;
- `src/generate_data.py` — воспроизводимая генерация JSON и CSV по seed;
- `src/solve.py` — модель, HiGHS (dual simplex), presolve, независимая проверка NumPy и сценарии;
- `results/` — оптимальный план, проверка ограничений, сценарии, сравнение теневой цены и альтернативный оптимум;
- `logs/solver_log.txt` — параметры решателя, статус, число итераций и результаты проверок;
- `figures/` — графики;
- `report.pdf`, `report.docx`, `report.md` — отчёт.

## Запуск

Проверено на Python 3.13.5 (`.python-version`).
```bash
python -m pip install -r requirements.txt
python run_all.py
```

Команда перегенерирует входные данные, решает модель, выполняет независимую проверку и сценарии, сохраняет CSV/лог, обновляет графики и пересобирает PDF/DOCX-отчёты.

## Допущения
1. Параметры синтетические: методичка задаёт масштаб задачи и seed, но не задаёт фиксированные значения или распределения генератора. Использованы распределения, явно описанные в `data/instance.json` и отчёте.
2. Запас каждого материала принят равным 62% ресурса, необходимого для полного удовлетворения сгенерированного спроса.
3. Выпуск непрерывный и измеряется в условных единицах; коэффициент вклада каждого продукта в цель равен 1.
4. Каждый продукт допускается выпускать на любой линии.
5. Время обработки зависит от пары «линия–продукт», но не от смены.
6. Не моделируются переналадки, минимальные партии, хранение, брак и целочисленность.
